## Ads and consent

- `ads_config` (Remote Config JSON, bundled default `assets/ad_config_defaults.json`): master switch `enabled`, cadence rules, ad unit IDs. Parsed by `AdConfig`.
- `config_admbob_mediator` (Remote Config JSON, bundled default `assets/config_admbob_mediator_defaults.json`): banner auto-refresh and optional ad unit overrides. Parsed by `AdmobMediatorConfig`. Assumptions (full list in `docs/REMOTE_CONFIG_ADS.md`):
  - `_IsDisabled` true → no auto-refresh, no retry backoff, no ID override.
  - `AutoRefreshIntervalSec` clamped to 15–120 s in code.
  - `FloorReloadDelaySec` = first retry delay after a failed banner load (min 15 s), doubling to a 120 s cap, reset on success.
  - `Type`, `Position`, `_Priority`, `_Version`, `_RewardedData` are parsed and logged only. Ask the owner before giving them behaviour.
  - `_ReConsentIntervalMinutes` is parsed and stored only; UMP alone decides when the form shows.
- Both configs are delivered once per launch (`RemoteJsonConfig`, shared with the game settings); remote values apply on the next launch; minimum fetch interval 12 h.
- No interstitial after a loss (owner request 2026-11-10): `ads_config.availability.interstitials.skip_after_loss` (default `true`). The page passes `afterLoss` to `AndroidBridge.onGameStarted(mode, restart, afterPromo, afterLoss)` when the previous game was not won (abandoned, stuck, or switched before any move; owner request 2026-11-10: only a new game after a win, or the first of a launch, can show one); `AdEligibility.interstitialOnGameStart(restart, afterLoss, skipAfterLoss)` then skips it. The game still counts as played and the interval and session / games-played conditions are unchanged, so the next game after a win can show the skipped one. `docs/REMOTE_CONFIG_ADS.md`.
- Ad unit precedence (`AdUnitResolver`): debug → test units; release → active mediator `AndroidCode` if non-empty → else `ads_config` → else no request. The rewarded video (v1.2 B1) always takes `ads_config.ad_unit_ids.rewarded` (`ca-app-pub-1626295360729995/3060836279`, in the bundled default since 2026-11-10 so it works from the first launch; `_RewardedData` is still only logged).
- Banner refresh (`AdsController`) only while resumed, banner visible, consent resolved, ads enabled, tutorial done, no full-screen ad, no request in flight; timers stop in onPause; slot height is fixed after the first ad. The AdMob console refresh for the Banner unit must be **off**.
- Consent (`AdsConsent`, UMP): checked on every launch; the loading screen holds at 3 suits until it resolves; the ads SDK starts only afterwards. Settings → Privacy Policy shows **Privacy options** when UMP reports it as required.
- Google Ads app campaigns (owner request 2026-11-06, `docs/ANALYTICS_EVENTS.md`): goal events `intro_complete` (5th warm-up deal won), `first_daily_win`, `wins_3`, `wins_10`, `day2_return` (first session on a calendar day after the first day), each once per player (`goals` in the saved state, so in the backup; `FreeCellCore.cleanGoals`/`goalsReached`/`markGoals`; an older save starts with its past progress marked sent), never for developer games or the quick win, and dropped by Android in test builds (`AnalyticsTracker.GOAL_EVENTS`, `sends(event, TEST_TOOLS)`: debug and qa). User properties `player_level`, `intro_complete` yes/no, `app_language` (page, `AndroidBridge.setUserProperty`, allow-list of 4, 36 characters) and `ads_removed` yes/no (Android, from the cached purchase and billing changes). Also new: `autocomplete_used`, `stats_reset`, `menu_open` for the screens opened from Settings, Game by Number, the Collection, Achievements and the Daily Bonus gift, and `rank` (Daily Rivals place) on `daily_challenge_complete`. Checked: Consent Mode v2 comes from UMP 4.0.0 (needs ≥ 3.2.0; Firebase starts first; consent mode must be on in AdMob), `AD_ID` is in the merged manifest, nothing disables Analytics or `ad_impression`.
- Debug-only "DEV · Tools" panel (`debugToolsView()`): Quick win (`quickWin()`, finishes the deal through the normal win path, so coins and level progress apply; not sent to analytics), level ±1, coins, shift "today" by days, add a Daily win, clear Daily history, lock themes, forget paid deals, show/reset the Daily Bonus, Missions celebration/complete/reset, restart the opening deals.
